## 项目简介

玄镜 AegisScope 是一款用于授权安全测试的 Chrome / Edge 扩展，主要处理网站前端资产的采集与分析。从当前页面出发，可以保存 HTML、JavaScript 和 SourceMap，识别网站技术栈，检查源码中的敏感信息、加密参数和接口风险，并查看 Vue / React 的运行时实例与路由。

各模块围绕同一个目标标签页工作，采集到的资源可继续用于泄露扫描和漏洞审计，识别到的框架可直接进入对应控制台。扫描结果保留来源、命中位置和检测依据，方便回到源码与请求中核查。插件同时提供备案查询、主动指纹扫描、API 批量测试，以及解除复制、WebRTC 防护、UA 和编码修改等辅助功能。

## 安装与更新

1. 解压 `玄镜 AegisScope_V2.3.5.zip`。
2. 打开 Chrome / Edge 扩展管理页，启用“开发者模式”。
3. 选择“加载已解压的扩展程序”，指向包含 `manifest.json` 的目录。
4. 打开插件，确认版本号为 **V2.3.5**，阅读并同意使用说明。

**更新已有安装：** 覆盖原加载目录后，点击扩展管理页的“重新加载”。如果使用新的版本目录，需要重新加载该目录并停用旧版本。更新后关闭旧工具页，从插件重新打开。

**刷新数据：** 首页“刷新全部”重新采集资产，并刷新当前显示的嗅探或备案面板。泄露扫描、漏洞审计和框架控制台是独立页面，使用各自的扫描或分析按钮。

目标页需要是浏览器可以正常访问的 HTTP/HTTPS 页面。浏览器内置页、扩展页和证书拦截页无法按普通站点分析；Vue/React 实例则需要等应用挂载后才能读取。

## 功能

### 保存资产

“保存资产”提供两种输出：

- **代码资源包**：将页面 HTML、内联和外链脚本，以及发现的 chunk、SourceMap、框架资源打包为 ZIP。
- **单文件页面**：将能够读取的页面资源内联到 HTML，保存当前页面快照。

页面内容从目标标签页采集，外链资源由扩展读取。请求会按目标主机尝试携带 Cookie，不会复制页面自定义的认证头。需要额外认证的资源可能下载失败；单文件快照也不能替代后端服务，离线时依赖接口的功能通常不可用。

![代码资产采集与保存](docs/images/code-assets.png)

### 备案查询

从当前页面正文、源码和链接中提取 ICP 备案号、公安备案号、许可证及相关链接，结果直接显示在弹窗内。

第三方接口结果作为补充，缓存一天。接口不可用不影响页面提取结果；备案信息以对应主管部门的查询结果为准。

![网站备案查询](docs/images/beian-query-overview.png)

### 网站嗅探

根据 HTML、响应头、Cookie、脚本、资源路径和运行时对象识别技术栈，包括 CMS、前端框架、JavaScript 库、UI 组件、CDN 等。识别到 Vue.js、React 或 jQuery 后，结果下方会显示对应工具入口。

结果分阶段更新。出现“部分完成”时，展开“采集范围说明”查看未覆盖的内容。嗅探结束后有两次延迟复查，用于补采晚加载的页面信号；关闭弹窗即停止复查。

<details>
<summary>检测方式与限制</summary>

- React 通过挂载根节点和 Fiber 识别，不依赖全局 `React` 变量。支持开放 Shadow DOM；空 Devtools 钩子不计为已挂载实例。
- DOM 规则同时检查节点及其属性或文本。通用标签、静态目录不单独作为产品证据，同一条件重复命中不重复计分。运行时版本优先于文件名推测，依赖关系、互斥条件和关联推断分别处理。
- 规则在 Worker 中运行，分析预算为 5 秒；超时保留已完成结果。重复刷新合并执行，缓存只复用已完成的分析，页面变化后丢弃旧任务结果。
- DOM、正文和样式采用有限采样，读取属性时跳过 getter。未加载代码、封闭 Shadow DOM 和采样范围外的特征可能漏检。
- 扩展规则包含此前补充的 215 项被动检测条件，另有 93 项关联推断目录。请求路径仅使用浏览器已观察到的请求；嗅探不主动探测 DNS、证书或额外路径，也不下载所有外部脚本。

</details>

### 指纹扫描

从网站嗅探进入，打开后自动扫描。与被动嗅探不同，指纹扫描会请求部分静态资源和常见产品路径，再结合响应头、标题、正文、图标 Hash 等条件匹配产品。

规则库包含 1.1 万余个产品指纹、2.2 万余个匹配器。结果列出产品、分类、置信度、状态码、响应长度、标题和命中证据。

| 扫描模式 | URL 上限 | 静态资源选取上限 | 请求并发 |
| --- | --- | --- | --- |
| 默认 | 56 | 14 | 2 |
| 扩展扫描 | 168 | 56 | 2 |

“扩展扫描”会重新开始任务。停止后保留已读取内容的分析结果，失败、截断及未请求的范围会一并显示。

![指纹扫描](docs/images/fingerprint-scan-overview.png)

### 泄露扫描

检查当前页面 HTML、已发现的脚本、代码依赖和 JSONP 响应，提取凭据、个人信息、加密参数及危险代码用法。结果按风险等级排列，并保留源码位置和引用证据。

常量追踪可以处理压缩后的短变量名、变量别名和静态配置对象，用于定位传入加密接口的 key、IV 等参数。它只做静态分析，不执行目标代码，也不会拿检测出的凭据访问服务。登录后返回当前用户自己的资料，需要结合接口权限判断，不能仅凭手机号或身份证号命中认定越权。

默认单资源读取上限为 **8 MiB**，扩展扫描为 **32 MiB**。读取失败、截断或跳过时，查看覆盖说明。

<details>
<summary>规则范围与读取限制</summary>

- 常规规则覆盖云密钥、Token、Cookie 凭证、Webhook、邮箱、手机号、身份证号、银行卡号、IP，以及弱加密、危险解码执行和打包/混淆特征。
- 加密参数追踪覆盖 CryptoJS 风格的 AES、DES、TripleDES、RC4/RC4Drop、Rabbit/RabbitLegacy、HMAC、PBKDF2/EvpKDF，常见 SM4、SM2 私钥调用，以及 Node crypto 风格接口和 Web Crypto 静态密钥导入。
- 支持同库 Utf8/Hex/Base64/Latin1 解析、部分 `Buffer.from`、`TextEncoder` 和常量字节数组；Web Crypto 可追踪 raw/PKCS#8 及 JWK 秘密字段。公钥、普通哈希消息不计为秘密材料，固定盐值单独列为信息项。
- 追踪限于单文件，无法确定的动态值、跨文件引用和复杂混淆不继续推断。源码长度上限为 8 × 1024 × 1024 个 UTF-16 代码单元，另有 30 万语法节点和遍历时间限制。这些预算不随扩展扫描提高；追踪失败不影响其他规则执行。解析器许可见 [Acorn LICENSE](scripts/lib/acorn-LICENSE.txt)。
- JSONP 使用已发现或后台已记录的资源，要求带有效 `callback`、`jsonp` 或 `jsonpcallback` 参数。已知非 GET 请求及可识别的退出、删除等操作地址不自动重放。
- 扩展读取失败时，可在同源目标页面内携带 Cookie 重试一次。重试不跟随重定向、不复制自定义认证头，仍受体积与超时限制。页面变化或停止扫描会终止读取；本功能不会持续录制全部接口响应。

</details>

### 漏洞审计

从源码、代码依赖和 SourceMap 中查找接口与风险用法，不自动遍历普通业务链接。主要检查接口文档暴露、客户端鉴权、对象或租户标识可控、支付参数，以及 DOM XSS、开放重定向、上传校验、CSRF、CORS 等问题。

有内置验证流程的条目提供“验证”按钮，执行时可能发送请求；依赖业务上下文的条目标记为“人工复核”。命中源码特征只是检查起点，最终结论需要看返回内容、账号权限和业务行为。

![漏洞审计](docs/images/vuln-audit.png)

### API 批量测试

位于漏洞审计页。选择请求方法、填写请求体后执行，支持 GET、POST、HEAD、OPTIONS、PUT、PATCH、DELETE，也可单条手动测试。批量任务每轮最多处理 160 个同源地址，跳过可识别的退出、删除等操作地址。

每个接口分别发送允许携带 Cookie 和省略 Cookie 的请求，展示状态及响应预览。界面的“登录态”不代表认证一定成功：插件不复制页面的 Authorization 等自定义头，Cookie 也受浏览器策略限制。响应预览会截断，HTTP 200 本身不能证明未授权访问成立。

POST、PUT、PATCH、DELETE 等方法执行前需要确认，可能改变业务数据。操作类接口如需测试，使用单条手动入口。

![API 批量测试](docs/images/api-batch-test.png)

### Vue/React 工具

首页“Vue/React 工具”默认进入 **玄镜 AegisScope Vue 控制台**。从嗅探结果点击 React 入口，则进入 **玄镜 AegisScope React 控制台**。两页顶部可互相切换。

#### React 运行时分析

读取页面暴露的 React 版本、挂载实例和路由配置，另列同源链接。支持筛选、JSON 导出和打开地址；动态参数路径不提供直接打开。未读到版本或路由时，页面会显示相应状态。

“打开”使用浏览器正常导航，访问权限由网站处理。控制台保持打开时，目标页同源跳转、刷新后仍保留列表，但标记为上次采集结果；需要更新时点击“分析实例”。跨源、关闭目标页或重新打开控制台会清除旧列表。分析等待超过 12 秒会超时退出，按钮恢复可用。

<details>
<summary>路由来源与快照</summary>

- 从 Fiber props、JSX 子节点、Context 和组件 props 中读取路由，支持旧版 `childRoutes`。菜单和链接另行标注，不计入路由配置数量。
- DOM、Fiber、配置读取分别限制预算。未加载路由、封闭 Shadow DOM 和其他 iframe 不在采集范围内；Hash/History 和 basename 生成的地址应与实际部署核对。
- 导出 JSON 的 `snapshot` 记录采集地址、当前地址、时间和过期状态。同源要求协议、主机、端口相同。分析期间导航会取消当前任务，旧任务返回不会覆盖新结果。

</details>

![V2.3.5 React 控制台](docs/images/react-router-tools.png)

#### Vue Router 分析

读取 Vue / Vue Router 实例、路由表、meta 和守卫信息。存在多个路由器时先选择实例；动态路由填写参数后再跳转。父级布局的入口重定向不会直接阻止子页面跳转。

Vue 控制台在目标页同源跳转、刷新后清除旧结果并自动分析。切换到其他源，或应用尚未挂载时，等页面就绪后点击“分析实例”。Hash 路由导出保留入口文件和查询参数。

跳转后立即回到登录页时，可在授权测试中开启“授权增强模式”重试；“恢复”会取消当前导航并清理增强状态。跳转成功只说明前端视图已通过本次检查，后端接口仍按原有权限处理。

<details>
<summary>跳转检查与恢复</summary>

- Vue Router 4 普通导航未到达目标时，可走运行时兼容导航。重定向只检查最终匹配记录，同时保留重定向解析、循环检测和组件挂载检查。
- 结果确认同时检查路由状态、浏览器地址和组件挂载，并观察约 0.7 秒。之后再次跳转或刷新，上一条结果即失效。
- 增强模式在本次跳转确认期间临时处理竞争导航，结束后恢复普通导航方法。关闭增强时恢复暂停的守卫，已取消注册的守卫不会重新加入；启用失败会提示并尝试回滚。该模式不提供登录凭据，也不改变后端权限。
- 同一文档复用分析辅助脚本，新文档重新安装。晚挂载应用会短暂重试，已卸载实例不会自动替换成另一个实例来操作。

</details>

### 浏览器辅助

**解除复制**：临时解除页面的选择、复制、右键、快捷键和粘贴限制。可以先启用再选择文字；勾选当前域名自动启用后，刷新页面仍会应用。部分文库和在线文档有专门适配。

![解除复制](docs/images/copy-unlock-overview.png)

**WebRTC**：提供浏览器隐私策略和页面级强阻断，用于限制本机网络地址暴露。强阻断会影响依赖 WebRTC 的视频、语音和在线客服功能。

![WebRTC 防泄漏](docs/images/webrtc-guard-overview.png)

**UA 修改**：切换页面 User-Agent，内置 66 个预设，包含桌面、移动端、App 内置浏览器及搜索爬虫。

![UA 修改](docs/images/ua-switcher-overview.png)

**编码修改**：检测页面当前编码，应用指定编码后刷新；支持恢复默认及本站 iframe，适用于 HTTP/HTTPS 的 HTML、纯文本和 XML 页面。

新版 Chrome/Edge 按当前标签页的网站生效。旧版浏览器使用地址兼容模式，仅覆盖当前地址和已勾选、已识别的本站 iframe；打开其他地址或新增 iframe 后需要重新应用。同一地址返回的文档类型变化时，先恢复默认。设置在关闭标签页或结束浏览器会话后清除。

BOM 或 Service Worker 缓存可能影响解码结果，以面板检测到的实际编码为准。

![V2.3.5 编码修改](docs/images/charset-switcher-overview.png)

## 版本记录

以下为各版本的变更记录。当前操作方式以本文功能说明为准。

### V2.3.5

- 新增 React 控制台：查看版本、挂载实例、路由和同源链接，支持筛选、JSON 导出及正常导航。首页入口改为“Vue/React 工具”，默认打开 Vue 控制台。
- 补充 React Stack、Fiber 和 renderer 识别，统一 React、Vue 控制台的字体、配色和布局。
- 扩展 React 路由读取：支持 JSX 嵌套配置、路径数组、旧版 childRoutes、Context 和组件 props。菜单、链接及静态 to/from 地址单独标注，修正挂载根重复计数、路由模式和基础路径继承。
- 修复 History 地址中的 `#` 被编码为 `%23`，区分 URL 片段与字面编码路径。
- 修复 React 分析长时间不结束：分阶段限制 DOM、Fiber 和配置读取，改用消息任务调度，增加总耗时限制及控制台 12 秒超时恢复；导航、关闭和迟到结果均按任务状态处理。
- React 工具在同源跳转、刷新后保留已采集列表和筛选条件，允许连续打开地址；跨源或关闭目标页时清理，导出附带快照状态。
- Vue 跳转后自动分析复用辅助脚本和路由发现结果，同源页面变化合并处理，晚挂载时短间隔重试；保持原有列表清理方式。
- 修复 Vue 兼容导航误将父布局重定向当作子页面重定向的问题，改为检查最终匹配记录，保留循环检测和视图挂载确认。

### V2.3.4

#### 泄露扫描修复

- 使用原始代码检测，保留完整命中内容和原始行列位置；不再通过插入换行美化扫描输入。静态规则的高置信命中不等于凭据有效或漏洞可利用。
- 扫描当前页面、可访问框架、已采集脚本和发现的代码依赖；支持 SourceMap 响应头、内联 base64/URI 映射、分段映射、sourceRoot 及可获取的缺失源码。历史内联脚本单独标注采集快照来源。
- HTTP 失败、超时、登录 HTML、编码异常、截断与数量上限均在覆盖说明和报告中显示。带查询参数的资源失败时保留原地址，不再删除参数后扫描另一个版本；重定向保留请求和响应两个地址。
- 普通扫描上限：单文件 8 MiB、总内容 96 MiB、2400 个资源、20000 处命中、每条规则每文件 1000 处；“扩展扫描”重新扫描当前页面，提高到 32 MiB、384 MiB、9600 个资源、50000 处命中、每规则 5000 处。达到上限明确提示，不能解释为无风险。
- 规则分析运行于独立 Worker；可停止扫描、终止请求和分析线程，页面跳转自动结束旧扫描。文本全文不长期保存在结果中，界面分批显示，JSON/Markdown 导出全部已保留的命中及覆盖信息，不受界面过滤条件影响。
- 公开客户端配置、IAM 实体标识符、anon 角色和明确示例标记降级为待核验线索；风险评分按同规则相同完整命中去重，仍保留每处来源。默认显示全部置信度。

“完成”只表示本轮发现的资源处理完成，不保证发现站点的全部未知资源。未加载的动态代码、复杂混淆、运行时拼接、无法访问的资源及浏览器不允许读取的页面仍可能需要人工补充。扫描不会使用发现的凭据请求云服务验证；本地样例回归不能换算为所有网站的准确率或召回率。
